```python
i = 1000
while i > 0:
    if (i % 3 == 0 and i % 5 == 0):
        print(sum)
    i -= 1```

## Code Overview

This Python script is designed to loop backward from 1000 down to 1, searching for numbers that are divisible by both 3 and 5 (i.e., multiples of 15).

### How it works:
- **`i = 1000`**: Sets the initial starting counter to 1000.
- **`while i > 0:`**: Runs a loop that decreases the counter with each step.
- **`if (i % 3 == 0 and i % 5 == 0):`**: Checks if the current number is a common multiple of 3 and 5.
- **`print(sum)`**: Attempts to print a value when the condition is met.
